# «المفضلة» — native iPhone app (Swift + SwiftUI)

A full rebuild of «المفضلة 2» for the iPhone only, in Apple's own language. It reads the backup files of the earlier apps exactly as they are.

- **FavCore** (`Packages/FavCore`) holds all the logic, with no interface:
  - the data model and the 18+ gate;
  - sanitising and work matching;
  - backups (plain and encrypted, with the same format) and local storage.
- **App** (`App/`) is the SwiftUI interface: Arabic, right to left, dark with gold.
- **Build:** done on GitHub Actions on Mac machines (`.github/workflows/build.yml`).
  - The Xcode project is generated by XcodeGen from `project.yml`.
  - The output is an unsigned IPA in the `latest` release, installed with AltStore.
- **Progress:** tracked in [`docs/CHECKLIST.md`](docs/CHECKLIST.md).

## Rules
- **The 18+ gate:** never weakened.
- **Data:** your data stays on your phone.
- **The repository:** contains neutral demo data only, never real data or API keys.
- **Backups:** the format is never broken. Imports never delete anything.
- **Sources:** official only (ThePornDB, StashDB, Wikimedia, your own Stash server). No scraping and no bypassing of protections.

## Installation
1. Download `Favorites-native.ipa` from the `latest` release.
2. Install it with AltStore.

It has a different identifier from «المفضلة 2», so both can be installed side by side. Export a backup from the old app, then import it from «المزيد» ← «استيراد نسخة احتياطية».

> Not yet verified on a real iPhone by the build process. That needs your trial.
